- 取り組んだレベル：発展
- やったこと：

書き方：もとの書き方はagent.pyにエージェントの中身とその他表示を書いていたが、Google の ADKでは表示機能は__main__.pyに書いている。adk web 自体の表示は ADK が提供している。
adk web での見え方：make_quizを一度呼び出している。元のコードでは agent.tool_plain(...) で登録し、ADK では Agent の tools=[...] に関数を渡している。

気づき：Google の ADKのほうがagent.pyが説明とツール一覧だけで簡潔だと感じました。またadk webは視覚的にエージェントの動きが見れてわかりやすいと思います。

### 作成したエージェントの使い方

リポジトリのルートで、環境変数または `.env` に `OPENAI_API_KEY` を設定し、次のコマンドを実行する。

```bash
uv run python3 -m app.learning_agent
```

起動後に質問を入力する。例えば「第2回の用語から確認問題を1問出してください」と入力すると、`make_quiz` を使って問題を作れる。終了するときは `exit` または `Ctrl+D`、応答を待っている途中に中断するときは `Ctrl+C` を使う。

ADK の Web 画面で試す場合は、リポジトリのルートで次を実行し、表示された URL を開く。

```bash
uv run adk web app/learning_agent
```
